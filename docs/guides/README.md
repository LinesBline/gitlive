# gitlive guides

Command-level walkthroughs, honest about what each flow gives you and
where its limits are. Every command here is real, shipped, and covered by
the test battery.

1. [Escape the tunnel](escape-the-tunnel.md) — a public entry node you own,
   for machines behind NAT. No tunnel account, no ToS ban on your own
   media, no company in the middle.
2. [Deploy with receipts](deploy-with-receipts.md) — signed manifests,
   closure gates, and deploy history as owner-signed git refs: the meter
   you can see, on hardware that bills you nothing per request.
3. [Two homes, one mesh](mesh-two-homes.md) — replicate state to a second
   machine you own, fail over, recover. One machine is daytime uptime;
   two are the honest 99%.
4. [Back up what you can't lose](back-up-what-you-cant-lose.md) — verified
   restic snapshots with receipts, and a restore that never touches live
   data.
5. [Graduate your name](graduate-your-name.md) — from a borrowed zone label
   to your own domain, in one command.

Each guide follows the same shape: **the fear it answers → the commands →
how you know it worked → honest limits.**
